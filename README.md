# Assignment 4 - NOAA Weather Forecast

This Python program uses NOAA web service endpoints to retrieve and display the 7-day forecast for Muncie,IN.

This program:
1. Retrieves JSON data from NOAA endpoint.
2. Extracts the forecast URL from the properties object.
3. Retrieves forecast data from the forecast endpoint.
4. Displays the name, temperature, and detailed forecast for all 14 forecast periods.
